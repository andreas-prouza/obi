# Feature specifications

Each larger change gets a file here before it is implemented. It records what is wanted and what was decided.

## Template

```markdown
# <Title>

- **Status:** draft | in progress | done
- **Type:** feature | improvement | bugfix


## Current situation

## Requirements

## Acceptance criteria

## Non-goals

## Decisions
```

| Status | Meaning |
|---|---|
| `draft` | Being written, not started |
| `in progress` | Being implemented or tested |
| `done` | Implemented, documented and released |
